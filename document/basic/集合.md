# Java 中的集合

## 1. 集合是什么

Java 集合是用来存储一组对象的容器。

常见用途：

```text
存储多个元素
去重
排序
快速查找
队列处理
栈结构
键值对存储
线程安全数据存储
```

Java 集合主要在：

```java
java.util
```

包下。

---

## 2. Java 集合体系

Java 集合主要分为两大类：

```text
Collection
Map
```

整体结构：

```text
Collection
├── List
│   ├── ArrayList
│   ├── LinkedList
│   └── Vector
│
├── Set
│   ├── HashSet
│   ├── LinkedHashSet
│   └── TreeSet
│
└── Queue
    ├── PriorityQueue
    ├── ArrayDeque
    └── LinkedList

Map
├── HashMap
├── LinkedHashMap
├── TreeMap
├── Hashtable
└── ConcurrentHashMap
```

---

## 3. Collection 和 Map 的区别

| 对比项 | Collection | Map |
|---|---|---|
| 存储结构 | 单列集合 | 双列集合 |
| 存储内容 | 一个一个元素 | key-value 键值对 |
| 常见子接口 | List、Set、Queue | 无 |
| 示例 | `List<String>` | `Map<String, Integer>` |

示例：

```java
List<String> list = new ArrayList<>();
list.add("Java");

Map<String, Integer> map = new HashMap<>();
map.put("Java", 100);
```

# 一、List 集合

## 4. List 特点

`List` 是有序集合。

特点：

```text
元素有序
可以重复
可以通过下标访问
```

常见实现类：

```text
ArrayList
LinkedList
Vector
```

---

## 5. ArrayList

### 5.1 ArrayList 特点

`ArrayList` 底层是数组。

特点：

```text
查询快
增删慢
线程不安全
允许 null
元素有序
允许重复
```

---

### 5.2 ArrayList 底层结构

```text
Object[] elementData
```

本质是数组。

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");
list.add("C");
```

底层类似：

```text
[A, B, C]
```

---

### 5.3 ArrayList 扩容机制

默认情况下：

```java
new ArrayList<>();
```

刚创建时，内部数组长度是 0。

第一次添加元素时，扩容为：

```text
10
```

后续扩容为原来的：

```text
1.5 倍
```

例如：

```text
10 -> 15 -> 22 -> 33
```

---

### 5.4 ArrayList 为什么查询快

因为底层是数组，可以通过下标直接定位：

```java
list.get(3);
```

时间复杂度：

```text
O(1)
```

---

### 5.5 ArrayList 为什么增删慢

如果在中间插入或删除元素，需要移动后面的元素。

例如删除下标 1：

```text
[A, B, C, D]
```

删除 `B` 后，`C`、`D` 要往前移动：

```text
[A, C, D]
```

时间复杂度：

```text
O(n)
```

---

## 6. LinkedList

### 6.1 LinkedList 特点

`LinkedList` 底层是双向链表。

特点：

```text
查询慢
头尾增删快
中间增删需要先查找位置
线程不安全
允许 null
元素有序
允许重复
```

---

### 6.2 LinkedList 底层结构

每个节点包含：

```text
前驱节点 prev
元素 item
后继节点 next
```

结构：

```text
null <- A <-> B <-> C -> null
```

---

### 6.3 LinkedList 适合场景

适合：

```text
频繁头部插入
频繁尾部插入
队列
双端队列
```

不适合：

```text
频繁随机访问
```

---

## 7. ArrayList 和 LinkedList 区别

| 对比项 | ArrayList | LinkedList |
|---|---|---|
| 底层结构 | 数组 | 双向链表 |
| 随机查询 | 快，O(1) | 慢，O(n) |
| 头尾增删 | 可能扩容或移动 | 快 |
| 中间增删 | 需要移动元素 | 需要先查找位置 |
| 内存占用 | 较少 | 较多，节点要存前后指针 |
| 使用场景 | 查询多 | 增删多，队列场景 |

面试回答：

```text
ArrayList 底层是数组，查询快，增删慢；
LinkedList 底层是双向链表，随机查询慢，头尾增删快。
实际开发中 ArrayList 用得更多。
```

---

## 8. Vector

`Vector` 和 `ArrayList` 类似，底层也是数组。

区别：

```text
Vector 是线程安全的
ArrayList 是线程不安全的
Vector 方法使用 synchronized 修饰
Vector 性能较差
```

实际开发中很少使用 `Vector`。

# 二、Set 集合

## 9. Set 特点

`Set` 是不允许重复元素的集合。

特点：

```text
元素不能重复
没有下标
是否有序取决于具体实现类
```

常见实现类：

```text
HashSet
LinkedHashSet
TreeSet
```

---

## 10. HashSet

### 10.1 HashSet 特点

```text
元素不能重复
无序
允许 null
线程不安全
底层基于 HashMap
```

示例：

```java
Set<String> set = new HashSet<>();
set.add("A");
set.add("B");
set.add("A");

System.out.println(set);
```

结果只有一个 `A`。

---

### 10.2 HashSet 如何去重

`HashSet` 底层使用 `HashMap`。

添加元素时，本质是：

```java
map.put(element, PRESENT);
```

去重依赖：

```text
hashCode()
equals()
```

判断流程：

```text
1. 先比较 hashCode
2. hashCode 不同，认为不是同一个对象
3. hashCode 相同，再比较 equals
4. equals 为 true，认为重复
```

---

### 10.3 自定义对象去重

如果 Set 中存储自定义对象，需要重写：

```java
hashCode()
equals()
```

示例：

```java
public class User {

    private Long id;
    private String name;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof User)) return false;

        User user = (User) o;
        return Objects.equals(id, user.id);
    }

    @Override
    public int hashCode() {
        return Objects.hash(id);
    }
}
```

---

## 11. LinkedHashSet

`LinkedHashSet` 是有序 Set。

特点：

```text
元素不能重复
保持插入顺序
底层基于 LinkedHashMap
允许 null
线程不安全
```

示例：

```java
Set<String> set = new LinkedHashSet<>();
set.add("B");
set.add("A");
set.add("C");
```

遍历顺序：

```text
B A C
```

---

## 12. TreeSet

`TreeSet` 是排序 Set。

特点：

```text
元素不能重复
元素自动排序
底层基于 TreeMap
不允许存储无法比较的对象
线程不安全
```

示例：

```java
Set<Integer> set = new TreeSet<>();
set.add(3);
set.add(1);
set.add(2);
```

遍历结果：

```text
1 2 3
```

---

## 13. HashSet、LinkedHashSet、TreeSet 区别

| 对比项 | HashSet | LinkedHashSet | TreeSet |
|---|---|---|---|
| 是否去重 | 是 | 是 | 是 |
| 是否有序 | 无序 | 插入有序 | 排序 |
| 底层结构 | HashMap | LinkedHashMap | TreeMap |
| 性能 | 高 | 略低于 HashSet | 较低 |
| 是否允许 null | 允许一个 null | 允许一个 null | 通常不建议 null |
| 使用场景 | 普通去重 | 去重并保持插入顺序 | 去重并排序 |

# 三、Queue 队列

## 14. Queue 特点

`Queue` 是队列接口。

特点：

```text
先进先出 FIFO
适合任务排队
适合生产消费模型
```

常见实现类：

```text
LinkedList
ArrayDeque
PriorityQueue
```

---

## 15. Queue 常用方法

| 方法 | 说明 |
|---|---|
| `offer()` | 添加元素，推荐 |
| `poll()` | 取出并删除队头元素 |
| `peek()` | 查看队头元素，不删除 |
| `add()` | 添加元素，失败抛异常 |
| `remove()` | 删除队头元素，失败抛异常 |
| `element()` | 查看队头元素，失败抛异常 |

推荐使用：

```java
offer()
poll()
peek()
```

---

## 16. ArrayDeque

`ArrayDeque` 是双端队列。

特点：

```text
底层数组
可以当队列使用
也可以当栈使用
性能通常优于 Stack 和 LinkedList
不允许 null
线程不安全
```

作为队列：

```java
Deque<String> deque = new ArrayDeque<>();
deque.offer("A");
deque.offer("B");

System.out.println(deque.poll());
```

作为栈：

```java
Deque<String> stack = new ArrayDeque<>();
stack.push("A");
stack.push("B");

System.out.println(stack.pop());
```

---

## 17. PriorityQueue

`PriorityQueue` 是优先队列。

特点：

```text
不是先进先出
按照优先级出队
底层是堆
默认小顶堆
线程不安全
```

示例：

```java
PriorityQueue<Integer> queue = new PriorityQueue<>();

queue.offer(3);
queue.offer(1);
queue.offer(2);

System.out.println(queue.poll()); // 1
```

# 四、Map 集合

## 18. Map 特点

`Map` 存储键值对：

```text
key-value
```

特点：

```text
key 不能重复
value 可以重复
一个 key 对应一个 value
```

常见实现类：

```text
HashMap
LinkedHashMap
TreeMap
Hashtable
ConcurrentHashMap
```

---

## 19. HashMap

### 19.1 HashMap 特点

```text
key 不能重复
value 可以重复
允许一个 null key
允许多个 null value
线程不安全
无序
查询效率高
```

示例：

```java
Map<String, Integer> map = new HashMap<>();

map.put("Java", 100);
map.put("MySQL", 90);
map.put("Java", 80);

System.out.println(map.get("Java")); // 80
```

相同 key 会覆盖旧值。

---

## 20. HashMap 底层结构

JDK 1.7：

```text
数组 + 链表
```

JDK 1.8：

```text
数组 + 链表 + 红黑树
```

结构：

```text
table 数组
  index 0 -> null
  index 1 -> Node -> Node
  index 2 -> TreeNode
  index 3 -> null
```

---

## 21. HashMap put 流程

大致流程：

```text
1. 根据 key 计算 hash
2. 根据 hash 计算数组下标
3. 如果位置为空，直接插入
4. 如果位置不为空，判断 key 是否相同
5. key 相同，覆盖 value
6. key 不同，挂到链表或红黑树上
7. 如果链表长度达到阈值，可能转红黑树
8. 如果元素数量超过阈值，触发扩容
```

---

## 22. HashMap 为什么线程不安全

多线程同时操作 HashMap 可能出现：

```text
数据覆盖
数据丢失
扩容异常
遍历异常
```

所以并发场景不要使用普通 `HashMap`。

并发场景推荐：

```java
ConcurrentHashMap
```

---

## 23. HashMap 扩容机制

默认初始容量：

```text
16
```

默认负载因子：

```text
0.75
```

扩容阈值：

```text
capacity * loadFactor
```

默认：

```text
16 * 0.75 = 12
```

当元素数量超过 12 时，触发扩容。

扩容后容量变为原来的：

```text
2 倍
```

例如：

```text
16 -> 32 -> 64 -> 128
```

---

## 24. 为什么 HashMap 容量是 2 的幂

因为 HashMap 通过下面方式计算数组下标：

```java
index = (n - 1) & hash;
```

当 `n` 是 2 的幂时：

```text
可以让 hash 分布更均匀
位运算效率高
扩容迁移更高效
```

---

## 25. HashMap 链表转红黑树

JDK 1.8 中，当链表过长时，会转为红黑树，提高查询性能。

条件：

```text
链表长度 >= 8
数组长度 >= 64
```

如果链表长度达到 8，但数组长度小于 64，优先扩容，而不是树化。

红黑树退化为链表条件：

```text
节点数量 <= 6
```

## 27. LinkedHashMap

`LinkedHashMap` 是有序 Map。

特点：

```text
继承 HashMap
底层维护双向链表
可以保持插入顺序
也可以实现访问顺序
```

示例：

```java
Map<String, Integer> map = new LinkedHashMap<>();

map.put("B", 2);
map.put("A", 1);
map.put("C", 3);
```

遍历顺序：

```text
B A C
```

---

## 28. LinkedHashMap 实现 LRU

`LinkedHashMap` 可以实现 LRU 缓存。

```java
public class LruCache<K, V> extends LinkedHashMap<K, V> {

    private final int capacity;

    public LruCache(int capacity) {
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > capacity;
    }
}
```

使用：

```java
Map<String, String> cache = new LruCache<>(3);

cache.put("A", "1");
cache.put("B", "2");
cache.put("C", "3");
cache.get("A");
cache.put("D", "4");
```

此时最久未访问的元素会被删除。

`TreeMap` 是排序 Map。

特点：

```text
key 不能重复
key 自动排序
底层红黑树
不允许 key 无法比较
线程不安全
```

示例：

```java
Map<Integer, String> map = new TreeMap<>();

map.put(3, "C");
map.put(1, "A");
map.put(2, "B");
```

遍历顺序：

```text
1 2 3
```

---

## 30. Hashtable

`Hashtable` 是早期线程安全 Map。

特点：

```text
线程安全
方法使用 synchronized 修饰
不允许 null key
不允许 null value
性能较差
基本被 ConcurrentHashMap 替代
```

---

## 31. ConcurrentHashMap

### 31.1 ConcurrentHashMap 特点

```text
线程安全
并发性能高
不允许 null key
不允许 null value
适合高并发场景
```

---

### 31.2 ConcurrentHashMap JDK 1.7 和 1.8 区别

| 版本 | 底层实现 |
|---|---|
| JDK 1.7 | Segment 分段锁 |
| JDK 1.8 | CAS + synchronized + 数组 + 链表 + 红黑树 |

---

### 31.3 为什么 ConcurrentHashMap 不允许 null

因为在并发场景下，`null` 会产生歧义。

例如：

```java
map.get("key") == null
```

无法判断：

```text
key 不存在
key 存在，但 value 是 null
```

为了避免并发语义混乱，`ConcurrentHashMap` 不允许 null。

---

## 32. HashMap、Hashtable、ConcurrentHashMap 区别

| 对比项 | HashMap | Hashtable | ConcurrentHashMap |
|---|---|---|---|
| 线程安全 | 否 | 是 | 是 |
| null key | 允许一个 | 不允许 | 不允许 |
| null value | 允许多个 | 不允许 | 不允许 |
| 性能 | 高 | 低 | 高 |
| 实现方式 | 数组+链表+红黑树 | synchronized | CAS + synchronized |
| 推荐使用 | 单线程 | 不推荐 | 并发场景 |

# 六、Comparable 和 Comparator

## 35. Comparable

`Comparable` 是自然排序。

类自己实现排序规则。

```java
public class User implements Comparable<User> {

    private Integer age;

    @Override
    public int compareTo(User other) {
        return this.age - other.age;
    }
}
```

使用：

```java
Collections.sort(userList);
```

---

## 36. Comparator

`Comparator` 是外部比较器。

不修改类本身，可以灵活指定排序规则。

```java
userList.sort((u1, u2) -> u1.getAge() - u2.getAge());
```

或者：

```java
userList.sort(Comparator.comparing(User::getAge));
```

倒序：

```java
userList.sort(Comparator.comparing(User::getAge).reversed());
```

---

## 37. Comparable 和 Comparator 区别

| 对比项 | Comparable | Comparator |
|---|---|---|
| 所在位置 | 类内部 | 类外部 |
| 方法 | `compareTo()` | `compare()` |
| 是否侵入类 | 是 | 否 |
| 灵活性 | 较低 | 高 |
| 使用场景 | 固定自然排序 | 多种排序规则 |

# 八、fail-fast 和 fail-safe

## 43. fail-fast 是什么

`fail-fast` 是快速失败机制。

当一个线程遍历集合时，如果另一个线程修改集合结构，可能抛出：

```text
ConcurrentModificationException
```

示例：

```java
List<String> list = new ArrayList<>();
list.add("A");
list.add("B");

for (String item : list) {
    if ("A".equals(item)) {
        list.remove(item); // 可能抛异常
    }
}
```

---

## 44. 正确删除方式

使用 Iterator 删除：

```java
Iterator<String> iterator = list.iterator();

while (iterator.hasNext()) {
    String item = iterator.next();

    if ("A".equals(item)) {
        iterator.remove();
    }
}
```

---

## 45. fail-safe 是什么

`fail-safe` 是安全失败机制。

遍历时使用副本，不会抛出 `ConcurrentModificationException`。

常见集合：

```text
CopyOnWriteArrayList
ConcurrentHashMap
```

# 九、线程安全集合

## 46. 常见线程安全集合

# 十一、常见面试题

## 52. ArrayList 和 LinkedList 区别？

```text
ArrayList 底层是数组，随机访问快，增删可能需要移动元素。
LinkedList 底层是双向链表，随机访问慢，头尾增删快。
实际开发中 ArrayList 使用更多。
```

---

## 53. HashMap 底层原理？

```text
HashMap 底层是数组 + 链表 + 红黑树。
put 时先根据 key 计算 hash，再根据 hash 定位数组下标。
如果位置为空直接插入；如果有元素，则比较 key，相同覆盖，不同则挂到链表或红黑树上。
当链表长度达到 8 且数组长度达到 64 时，链表转红黑树。
当元素数量超过容量 * 负载因子时，触发扩容，容量变为原来的 2 倍。
```

---

## 54. HashMap 为什么线程不安全？

```text
多线程同时 put、resize 或修改链表/红黑树时，可能导致数据覆盖、数据丢失、结构异常。
所以并发场景应该使用 ConcurrentHashMap。
```

---

## 55. HashMap 和 ConcurrentHashMap 区别？

```text
HashMap 线程不安全，允许 null key 和 null value。
ConcurrentHashMap 线程安全，不允许 null key 和 null value。
JDK 1.8 中 ConcurrentHashMap 通过 CAS + synchronized 保证并发安全。
```

---

## 56. HashSet 如何去重？

```text
HashSet 底层基于 HashMap，元素作为 key 存储。
去重依赖 hashCode 和 equals。
先比较 hashCode，如果 hashCode 相同，再比较 equals。
```

---

## 57. HashMap 为什么容量是 2 的幂？

```text
HashMap 使用 (n - 1) & hash 计算数组下标。
当容量 n 是 2 的幂时，可以让 hash 分布更均匀，同时位运算效率高。
```

---

## 58. ArrayList 扩容机制？

```text
ArrayList 底层是数组。
无参构造创建时数组长度为 0，第一次 add 时扩容为 10。
后续扩容为原容量的 1.5 倍。
```

---

## 59. Iterator 删除为什么安全？

```text
Iterator 内部维护了 expectedModCount。
使用 iterator.remove() 会同步更新修改次数，避免 ConcurrentModificationException。
直接使用 list.remove() 会导致集合修改次数和迭代器期望修改次数不一致。
```

---

## 60. Comparable 和 Comparator 区别？

```text
Comparable 是类内部定义的自然排序，需要实现 compareTo 方法。
Comparator 是外部比较器，需要实现 compare 方法，更灵活，可以定义多种排序规则。
```

---

# 十二、总结

Java 集合主要分为 Collection 和 Map 两大体系。

Collection 下面有 List、Set、Queue。List 是有序可重复集合，常见实现有 ArrayList 和 LinkedList。ArrayList 底层是数组，查询快，增删慢；LinkedList 底层是双向链表，随机查询慢，头尾增删快。

Set 是不允许重复的集合，常见实现有 HashSet、LinkedHashSet 和 TreeSet。HashSet 底层基于 HashMap，去重依赖 hashCode 和 equals；LinkedHashSet 可以保持插入顺序；TreeSet 可以排序，底层基于红黑树。

Map 是键值对集合，常见实现有 HashMap、LinkedHashMap、TreeMap 和 ConcurrentHashMap。HashMap 底层在 JDK 1.8 中是数组、链表和红黑树，默认容量是 16，负载因子是 0.75，链表长度达到 8 且数组长度达到 64 时会树化。HashMap 线程不安全，并发场景应该使用 ConcurrentHashMap。

集合选型时，如果是普通 List，一般优先使用 ArrayList；如果需要去重用 HashSet；如果需要排序用 TreeSet 或 TreeMap；如果需要并发安全的 Map，用 ConcurrentHashMap；如果读多写少的线程安全 List，可以使用 CopyOnWriteArrayList。

---

## 61. 一句话总结

> Java 集合是用来存储和操作对象容器的框架，核心包括 List、Set、Queue 和 Map；List 关注有序可重复，Set 关注去重，Queue 关注队列模型，Map 关注键值对存储，实际开发中最常用的是 ArrayList、HashMap、HashSet、ConcurrentHashMap。
