# 数据结构总结

数据结构是指：**数据的组织、存储和访问方式**。  
核心目标是：**提高数据查询、插入、删除和修改的效率**。

---

## 1. 常见数据结构分类

| 类型 | 常见结构 |
|---|---|
| 线性结构 | 数组、链表、栈、队列 |
| 散列结构 | HashMap、HashSet |
| 树形结构 | 二叉树、搜索二叉树、平衡树、红黑树、B+ 树 |
| 堆结构 | 大顶堆、小顶堆 |
| 图结构 | 有向图、无向图、加权图 |
| 高级结构 | 跳表、Trie、布隆过滤器 |

---

## 2. 数组 Array

### 特点

```text
内存连续
支持下标随机访问
```

### 优势

- 查询快，按下标访问时间复杂度是 `O(1)`。
- 内存连续，缓存友好。

### 劣势

- 插入、删除慢，需要移动元素。
- 大小通常固定，扩容成本高。

### 场景

```text
ArrayList
查询多、增删少
按下标访问
```

---

## 3. 链表 LinkedList

### 特点

```text
节点不连续
每个节点保存数据和指针
```

### 优势

- 插入、删除快。
- 不需要连续内存。

### 劣势

- 查询慢，需要从头遍历。
- 指针额外占用内存。

### 场景

```text
LinkedList
LRU 链表
频繁插入删除
```

---

## 4. 栈 Stack

### 特点

```text
先进后出 LIFO
```

### 常见操作

```text
push 入栈
pop 出栈
peek 查看栈顶
```

### 场景

```text
方法调用栈
括号匹配
表达式求值
递归转非递归
浏览器后退
```

---

## 5. 队列 Queue

### 特点

```text
先进先出 FIFO
```

### 常见类型

| 类型 | 说明 |
|---|---|
| 普通队列 | 先进先出 |
| 双端队列 | 两端都可以入队出队 |
| 阻塞队列 | 队列为空或满时阻塞 |
| 优先级队列 | 按优先级出队 |
| 延迟队列 | 到期后才能出队 |

### 场景

```text
线程池任务队列
消息队列
生产者消费者
异步任务
```

---

## 6. 哈希表 Hash Table

### 特点

```text
通过 hash 函数定位数组下标
```

### 优势

- 查询、插入、删除平均时间复杂度是 `O(1)`。

### 劣势

- 可能发生哈希冲突。
- 扩容成本较高。
- 无序。

### 冲突解决

```text
链地址法
开放寻址法
```

### 场景

```text
HashMap
HashSet
缓存
去重
快速查找
```

---

## 7. 树 Tree

### 特点

树是一种层级结构。

```text
根节点
子节点
叶子节点
```

### 常见树

| 类型 | 说明 |
|---|---|
| 二叉树 | 每个节点最多两个子节点 |
| 二叉搜索树 | 左子树小，右子树大 |
| AVL 树 | 严格平衡二叉搜索树 |
| 红黑树 | 近似平衡二叉搜索树 |
| B 树 | 多路平衡搜索树 |
| B+ 树 | 数据库索引常用结构 |

---

## 8. 红黑树

### 特点

红黑树是一种近似平衡二叉搜索树。

### 优势

- 查询、插入、删除复杂度都是 `O(logN)`。
- 插入删除时旋转次数相对较少。
- 工程实现性能稳定。

### 场景

```text
TreeMap
TreeSet
HashMap 链表树化
Linux 调度器
```

---

## 9. B+ 树

### 特点

B+ 树是数据库索引常用结构。

核心特点：

```text
非叶子节点只存索引
叶子节点存数据
叶子节点之间用链表连接
```

### 优势

- 树高低，磁盘 IO 少。
- 范围查询效率高。
- 适合数据库索引。

### 场景

```text
MySQL InnoDB 索引
文件系统索引
范围查询
```

---

## 10. 堆 Heap

### 特点

堆是一种特殊的完全二叉树。

| 类型 | 说明 |
|---|---|
| 大顶堆 | 父节点大于等于子节点 |
| 小顶堆 | 父节点小于等于子节点 |

### 场景

```text
优先级队列
TopK 问题
堆排序
定时任务调度
```

---

## 11. 图 Graph

### 特点

图由顶点和边组成。

```text
顶点 Vertex
边 Edge
```

### 常见类型

```text
有向图
无向图
加权图
无权图
```

### 存储方式

| 方式 | 说明 |
|---|---|
| 邻接矩阵 | 查询边快，占用空间大 |
| 邻接表 | 节省空间，适合稀疏图 |

### 场景

```text
社交关系
地图导航
推荐系统
网络拓扑
依赖关系分析
```

---

## 12. 跳表 SkipList

### 特点

跳表是在链表基础上增加多级索引。

```text
多级索引
  ↓
快速跳跃查找
```

### 优势

- 查询、插入、删除平均复杂度 `O(logN)`。
- 实现比红黑树简单。
- 支持范围查询。

### 场景

```text
Redis ZSet
有序集合
范围查询
```

---

## 13. Trie 字典树

### 特点

Trie 适合处理字符串前缀匹配。

```text
root
 ├── a
 │   └── p
 │       └── p
```

### 场景

```text
搜索自动补全
敏感词匹配
前缀查询
字典匹配
```

---

## 14. 布隆过滤器 Bloom Filter

### 特点

布隆过滤器用于判断一个元素是否可能存在。

```text
不存在：一定不存在
存在：可能存在
```

### 优势

- 内存占用小。
- 查询速度快。

### 劣势

- 有误判率。
- 一般不支持删除。

### 场景

```text
缓存穿透
黑名单
URL 去重
大数据去重
```

---

## 15. 常见时间复杂度

| 数据结构 | 查询 | 插入 | 删除 |
|---|---:|---:|---:|
| 数组 | `O(1)` / `O(N)` | `O(N)` | `O(N)` |
| 链表 | `O(N)` | `O(1)` | `O(1)` |
| 栈 | `O(1)` | `O(1)` | `O(1)` |
| 队列 | `O(1)` | `O(1)` | `O(1)` |
| 哈希表 | `O(1)` | `O(1)` | `O(1)` |
| 二叉搜索树 | `O(logN)` / `O(N)` | `O(logN)` | `O(logN)` |
| 红黑树 | `O(logN)` | `O(logN)` | `O(logN)` |
| 堆 | `O(N)` | `O(logN)` | `O(logN)` |
| 跳表 | `O(logN)` | `O(logN)` | `O(logN)` |

---

## 16. 总结

常见数据结构包括数组、链表、栈、队列、哈希表、树、堆、图、跳表、Trie 和布隆过滤器。

数组适合随机访问，链表适合频繁插入删除；栈是先进后出，队列是先进先出；哈希表适合快速查找和去重；树适合有序数据查询；红黑树用于稳定的 `O(logN)` 查询；B+ 树适合数据库索引；堆适合优先级队列和 TopK；跳表适合有序集合和范围查询；布隆过滤器适合缓存穿透和大数据去重。

一句话总结：

```text
数组查得快，链表增删快；
栈先进后出，队列先进先出；
Hash 查找快，树适合有序查找；
堆适合 TopK，跳表适合范围查询，布隆过滤器适合快速判重。
```
