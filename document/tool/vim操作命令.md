# Vim 常用操作命令

## 1. Vim 模式

| 模式 | 说明 | 进入方式 |
|---|---|---|
| 普通模式 | 移动光标、复制、删除、粘贴 | 默认模式，按 `Esc` |
| 插入模式 | 输入文本 | `i`、`a`、`o` |
| 可视模式 | 选择文本 | `v`、`V`、`Ctrl + v` |
| 命令模式 | 保存、退出、搜索、替换 | 普通模式下输入 `:` |

---

## 2. 进入插入模式

| 命令 | 说明 |
|---|---|
| `i` | 在光标前插入 |
| `I` | 在当前行行首插入 |
| `a` | 在光标后插入 |
| `A` | 在当前行行尾插入 |
| `o` | 在当前行下面新建一行 |
| `O` | 在当前行上面新建一行 |

---

## 3. 光标移动

| 命令 | 说明 |
|---|---|
| `h` | 向左移动 |
| `j` | 向下移动 |
| `k` | 向上移动 |
| `l` | 向右移动 |
| `w` | 移动到下一个单词开头 |
| `b` | 移动到上一个单词开头 |
| `e` | 移动到当前/下一个单词结尾 |
| `0` | 移动到行首 |
| `^` | 移动到行首第一个非空字符 |
| `$` | 移动到行尾 |
| `gg` | 移动到文件开头 |
| `G` | 移动到文件末尾 |
| `nG` | 移动到第 n 行，例如 `10G` |
| `Ctrl + f` | 向下翻页 |
| `Ctrl + b` | 向上翻页 |
| `Ctrl + d` | 向下翻半页 |
| `Ctrl + u` | 向上翻半页 |

---

## 4. 删除操作

| 命令 | 说明 |
|---|---|
| `x` | 删除当前字符 |
| `dd` | 删除当前行 |
| `ndd` | 删除 n 行，例如 `3dd` |
| `dw` | 删除一个单词 |
| `d$` | 删除到行尾 |
| `d0` | 删除到行首 |
| `D` | 删除到行尾，等同于 `d$` |

---

## 5. 复制和粘贴

| 命令 | 说明 |
|---|---|
| `yy` | 复制当前行 |
| `nyy` | 复制 n 行，例如 `3yy` |
| `yw` | 复制一个单词 |
| `y$` | 复制到行尾 |
| `p` | 粘贴到光标后/下一行 |
| `P` | 粘贴到光标前/上一行 |

---

## 6. 修改和替换

| 命令 | 说明 |

## 7. 撤销和恢复

| 命令 | 说明 |
|---|---|
| `u` | 撤销 |
| `Ctrl + r` | 恢复撤销 |

## 8. 查找

| 命令 | 说明 |
|---|---|
| `/keyword` | 向下查找 keyword |
| `?keyword` | 向上查找 keyword |
| `n` | 查找下一个 |

---

## 9. 替换

### 当前行替换第一个匹配

```vim
:s/old/new/
```

### 当前行替换所有匹配

```vim
:s/old/new/g
```

### 全文替换第一个匹配

```vim
:%s/old/new/
```

### 全文替换所有匹配

```vim
:%s/old/new/g
```

### 全文替换并确认

```vim
:%s/old/new/gc
```

说明：

| 参数 | 含义 |
|---|---|
| `%` | 全文 |
| `s` | substitute，替换 |
| `g` | global，当前行所有匹配 |
| `c` | confirm，逐个确认 |

## 17. 常用操作示例

### 删除第 10 行到第 20 行

```vim
:10,20d
```

### 复制第 10 行到第 20 行

```vim
:10,20y
```

### 将第 10 行到第 20 行的 old 替换为 new

```vim
:10,20s/old/new/g
```

### 删除全文

```vim
:%d
```

### 复制全文

```vim
:%y
```

### 跳转到第 100 行

```vim
:100
```

或者：

```vim
100G
```

# 总结

Vim 常用命令可以按下面几类记：

```text
移动：h j k l / w / b / gg / G
编辑：i / a / o / x / r / cw
删除：dd / dw / d$ / D
复制：yy / yw / y$
粘贴：p / P
查找：/keyword / n / N
替换：:%s/old/new/g
保存退出：:w / :q / :wq / :q!
```
