# 二、反转链表

## 1. 题目描述

给定单链表头节点 `head`，反转链表并返回新的头节点。

示例：

```text
输入：1 -> 2 -> 3 -> 4 -> 5
输出：5 -> 4 -> 3 -> 2 -> 1
```

---

## 2. 解题思路

使用三个指针：

```text
prev：前一个节点
curr：当前节点
next：临时保存下一个节点
```

遍历链表时，把当前节点的 `next` 指向前一个节点。

---

## 3. Java 代码

```java
public class Solution {

    public ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;

        while (curr != null) {
            ListNode next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }

        return prev;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

# 三、合并两个有序链表

## 1. 题目描述

给定两个升序链表，将它们合并成一个新的升序链表。

示例：

```text
输入：
1 -> 2 -> 4
1 -> 3 -> 4

输出：
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

---

## 2. 解题思路

使用虚拟头节点 `dummy`，然后用两个指针分别遍历两个链表。

每次选择较小的节点接到结果链表后面。

---

## 3. Java 代码

```java
public class Solution {

    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val <= list2.val) {
                curr.next = list1;
                list1 = list1.next;
            } else {
                curr.next = list2;
                list2 = list2.next;
            }
            curr = curr.next;
        }

        curr.next = list1 != null ? list1 : list2;

        return dummy.next;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(m + n)
空间复杂度：O(1)
```

# 四、LRU 缓存

## 1. 题目描述

设计一个 LRU 缓存，支持：

```text
get(key)
put(key, value)
```

要求：

```text
get 和 put 的时间复杂度都是 O(1)
```

LRU 全称：

```text
Least Recently Used
```

意思是：

```text
最近最少使用。
```

当缓存满时，淘汰最久没有被访问的数据。

---

## 2. 解题思路

使用：

```text
HashMap + 双向链表
```

其中：

```text
HashMap：保证 O(1) 查找节点
双向链表：维护访问顺序
```

链表头部表示最近使用，链表尾部表示最久未使用。

---

## 3. Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class LRUCache {

    private static class Node {
        int key;
        int value;
        Node prev;
        Node next;

        Node() {}

        Node(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }

    private final int capacity;
    private final Map<Integer, Node> map;

    private final Node head;
    private final Node tail;

    public LRUCache(int capacity) {
        this.capacity = capacity;
        this.map = new HashMap<>();

        this.head = new Node();
        this.tail = new Node();

        head.next = tail;
        tail.prev = head;
    }

    public int get(int key) {
        Node node = map.get(key);

        if (node == null) {
            return -1;
        }

        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);

        if (node != null) {
            node.value = value;
            moveToHead(node);
            return;
        }

        Node newNode = new Node(key, value);
        map.put(key, newNode);
        addToHead(newNode);

        if (map.size() > capacity) {
            Node removed = removeTail();
            map.remove(removed.key);
        }
    }

    private void moveToHead(Node node) {
        removeNode(node);
        addToHead(node);
    }

    private void addToHead(Node node) {
        node.prev = head;
        node.next = head.next;

        head.next.prev = node;
        head.next = node;
    }

    private void removeNode(Node node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    private Node removeTail() {
        Node node = tail.prev;
        removeNode(node);
        return node;
    }
}
```

---

## 4. 复杂度分析

```text
get 时间复杂度：O(1)
put 时间复杂度：O(1)
空间复杂度：O(capacity)
```

# 五、二叉树层序遍历

## 1. 题目描述

给定二叉树根节点，返回其层序遍历结果。

示例：

```text
输入：
    3
   / \
  9  20
     / \
    15  7

输出：
[
  [3],
  [9,20],
  [15,7]
]
```

---

## 2. 解题思路

层序遍历使用队列 BFS。

每次处理一层节点：

```text
1. 记录当前队列大小 size
2. 循环 size 次，取出当前层所有节点
3. 把下一层节点加入队列
```

---

## 3. Java 代码

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;

public class Solution {

    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();

        if (root == null) {
            return result;
        }

        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int size = queue.size();
            List<Integer> level = new ArrayList<>();

            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);

                if (node.left != null) {
                    queue.offer(node.left);
                }

                if (node.right != null) {
                    queue.offer(node.right);
                }
            }

            result.add(level);
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

# 六、二叉树最大深度

## 1. 题目描述

给定二叉树根节点，求最大深度。

最大深度是从根节点到最远叶子节点的最长路径上的节点数。

---

## 2. 解题思路

递归求解：

```text
当前树最大深度 = max(左子树最大深度, 右子树最大深度) + 1
```

---

## 3. Java 代码

```java
public class Solution {

    public int maxDepth(TreeNode root) {
        if (root == null) {
            return 0;
        }

        int leftDepth = maxDepth(root.left);
        int rightDepth = maxDepth(root.right);

        return Math.max(leftDepth, rightDepth) + 1;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(h)
```

其中 `h` 是树的高度。

# 七、最长无重复子串

## 1. 题目描述

给定字符串 `s`，求不含重复字符的最长子串长度。

示例：

```text
输入：abcabcbb
输出：3
解释：最长无重复子串是 abc
```

---

## 2. 解题思路

使用滑动窗口。

维护一个窗口 `[left, right]`，保证窗口内没有重复字符。

当遇到重复字符时，移动左边界。

---

## 3. Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class Solution {

    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> map = new HashMap<>();

        int left = 0;
        int result = 0;

        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);

            if (map.containsKey(c)) {
                left = Math.max(left, map.get(c) + 1);
            }

            map.put(c, right);
            result = Math.max(result, right - left + 1);
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(k)
```

其中 `k` 是字符集大小。

# 八、最长回文子串

## 1. 题目描述

给定字符串 `s`，返回最长回文子串。

示例：

```text
输入：babad
输出：bab 或 aba
```

---

## 2. 解题思路

使用中心扩展法。

回文串有两种中心：

```text
1. 一个字符作为中心，例如 aba
2. 两个字符作为中心，例如 abba
```

遍历每个位置，从中心向两边扩展。

---

## 3. Java 代码

```java
public class Solution {

    public String longestPalindrome(String s) {
        if (s == null || s.length() < 2) {
            return s;
        }

        int start = 0;
        int end = 0;

        for (int i = 0; i < s.length(); i++) {
            int len1 = expand(s, i, i);
            int len2 = expand(s, i, i + 1);

            int len = Math.max(len1, len2);

            if (len > end - start + 1) {
                start = i - (len - 1) / 2;
                end = i + len / 2;
            }
        }

        return s.substring(start, end + 1);
    }

    private int expand(String s, int left, int right) {
        while (left >= 0 
                && right < s.length() 
                && s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }

        return right - left - 1;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n²)
空间复杂度：O(1)
```

# 九、两数之和

## 1. 题目描述

给定整数数组 `nums` 和目标值 `target`，找出数组中和为目标值的两个数下标。

示例：

```text
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
```

---

## 2. 解题思路

使用 HashMap 存储：

```text
数字 -> 下标
```

遍历数组时，判断 `target - 当前数字` 是否已经出现过。

---

## 3. Java 代码

```java
import java.util.HashMap;
import java.util.Map;

public class Solution {

    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];

            if (map.containsKey(need)) {
                return new int[]{map.get(need), i};
            }

            map.put(nums[i], i);
        }

        return new int[0];
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

# 十、三数之和

## 1. 题目描述

给定整数数组 `nums`，找出所有不重复的三元组，使得：

```text
a + b + c = 0
```

示例：

```text
输入：[-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

---

## 2. 解题思路

先排序，然后固定一个数，再用双指针找另外两个数。

步骤：

```text
1. 排序
2. 遍历 i，固定 nums[i]
3. left = i + 1，right = n - 1
4. 根据三数之和移动左右指针
5. 跳过重复元素
```

---

## 3. Java 代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

public class Solution {

    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();

        if (nums == null || nums.length < 3) {
            return result;
        }

        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {
            if (nums[i] > 0) {
                break;
            }

            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum == 0) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));

                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }

                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }

                    left++;
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n²)
空间复杂度：O(1)，不算返回结果
```

# 十一、有效括号

## 1. 题目描述

给定只包含 `()[]{}` 的字符串，判断括号是否有效。

有效规则：

```text
左括号必须用相同类型的右括号闭合；
左括号必须以正确顺序闭合。
```

---

## 2. 解题思路

使用栈。

遇到左括号入栈。

遇到右括号时，判断栈顶是否匹配。

---

## 3. Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class Solution {

    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } else {
                if (stack.isEmpty() || stack.pop() != c) {
                    return false;
                }
            }
        }

        return stack.isEmpty();
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

# 十二、滑动窗口最大值

## 1. 题目描述

给定数组 `nums` 和窗口大小 `k`，返回每个滑动窗口中的最大值。

示例：

```text
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
```

---

## 2. 解题思路

使用单调队列。

队列中保存数组下标，并保持对应元素从大到小。

每次窗口右移时：

```text
1. 移除窗口外的下标
2. 移除队尾比当前元素小的下标
3. 当前下标入队
4. 队首就是当前窗口最大值
```

---

## 3. Java 代码

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class Solution {

    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums == null || nums.length == 0 || k <= 0) {
            return new int[0];
        }

        int[] result = new int[nums.length - k + 1];
        Deque<Integer> deque = new ArrayDeque<>();

        for (int i = 0; i < nums.length; i++) {
            while (!deque.isEmpty() && deque.peekFirst() <= i - k) {
                deque.pollFirst();
            }

            while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
                deque.pollLast();
            }

            deque.offerLast(i);

            if (i >= k - 1) {
                result[i - k + 1] = nums[deque.peekFirst()];
            }
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n)
空间复杂度：O(k)
```

# 十三、TopK 高频元素

## 1. 题目描述

给定整数数组 `nums` 和整数 `k`，返回出现频率最高的 `k` 个元素。

示例：

```text
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

---

## 2. 解题思路

使用：

```text
HashMap 统计频率 + 小顶堆维护 TopK
```

堆中保存频率最高的 k 个元素。

当堆大小超过 k 时，弹出频率最小的元素。

---

## 3. Java 代码

```java
import java.util.HashMap;
import java.util.Map;
import java.util.PriorityQueue;

public class Solution {

    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freqMap = new HashMap<>();

        for (int num : nums) {
            freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
        }

        PriorityQueue<int[]> heap = new PriorityQueue<>(
                (a, b) -> a[1] - b[1]
        );

        for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
            heap.offer(new int[]{entry.getKey(), entry.getValue()});

            if (heap.size() > k) {
                heap.poll();
            }
        }

        int[] result = new int[k];

        for (int i = k - 1; i >= 0; i--) {
            result[i] = heap.poll()[0];
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n log k)
空间复杂度：O(n)
```

# 十四、快速排序

## 1. 算法思想

快速排序采用分治思想。

核心流程：

```text
1. 选择一个基准值 pivot
2. 将小于 pivot 的元素放左边
3. 将大于 pivot 的元素放右边
4. 递归排序左右两部分
```

---

## 2. Java 代码

```java
public class QuickSort {

    public void quickSort(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }

        quickSort(nums, 0, nums.length - 1);
    }

    private void quickSort(int[] nums, int left, int right) {
        if (left >= right) {
            return;
        }

        int pivotIndex = partition(nums, left, right);

        quickSort(nums, left, pivotIndex - 1);
        quickSort(nums, pivotIndex + 1, right);
    }

    private int partition(int[] nums, int left, int right) {
        int pivot = nums[right];
        int i = left;

        for (int j = left; j < right; j++) {
            if (nums[j] <= pivot) {
                swap(nums, i, j);
                i++;
            }
        }

        swap(nums, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {
        if (i == j) {
            return;
        }

        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

---

## 3. 复杂度分析

```text
平均时间复杂度：O(n log n)
最坏时间复杂度：O(n²)
空间复杂度：O(log n)
```

---

## 4. 注意事项

快速排序最坏情况出现在：

```text
每次 pivot 都选到最大值或最小值。
```

优化方式：

```text
1. 随机选择 pivot
2. 三数取中
3. 小数组使用插入排序
```

# 十五、归并排序

## 1. 算法思想

归并排序采用分治思想。

核心流程：

```text
1. 将数组不断拆分成两半
2. 分别排序左右两部分
3. 将两个有序数组合并
```

---

## 2. Java 代码

```java
public class MergeSort {

    public void mergeSort(int[] nums) {
        if (nums == null || nums.length <= 1) {
            return;
        }

        int[] temp = new int[nums.length];
        mergeSort(nums, 0, nums.length - 1, temp);
    }

    private void mergeSort(int[] nums, int left, int right, int[] temp) {
        if (left >= right) {
            return;
        }

        int mid = left + (right - left) / 2;

        mergeSort(nums, left, mid, temp);
        mergeSort(nums, mid + 1, right, temp);

        merge(nums, left, mid, right, temp);
    }

    private void merge(int[] nums, int left, int mid, int right, int[] temp) {
        int i = left;
        int j = mid + 1;
        int index = left;

        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) {
                temp[index++] = nums[i++];
            } else {
                temp[index++] = nums[j++];
            }
        }

        while (i <= mid) {
            temp[index++] = nums[i++];
        }

        while (j <= right) {
            temp[index++] = nums[j++];
        }

        for (int k = left; k <= right; k++) {
            nums[k] = temp[k];
        }
    }
}
```

---

## 3. 复杂度分析

```text
时间复杂度：O(n log n)
空间复杂度：O(n)
稳定性：稳定排序
```

# 十六、岛屿数量

## 1. 题目描述

给定由 `'1'` 和 `'0'` 组成的二维网格：

```text
1 表示陆地
0 表示水
```

求岛屿数量。

岛屿由水平或垂直方向相邻的陆地连接形成。

---

## 2. 解题思路

遍历网格。

当遇到 `'1'` 时，说明发现一个新岛屿，数量加 1，然后用 DFS 或 BFS 把整座岛屿都标记为已访问。

---

## 3. Java 代码

```java
public class Solution {

    public int numIslands(char[][] grid) {
        if (grid == null || grid.length == 0) {
            return 0;
        }

        int rows = grid.length;
        int cols = grid[0].length;
        int count = 0;

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == '1') {
                    count++;
                    dfs(grid, i, j);
                }
            }
        }

        return count;
    }

    private void dfs(char[][] grid, int row, int col) {
        if (row < 0 
                || row >= grid.length 
                || col < 0 
                || col >= grid[0].length 
                || grid[row][col] != '1') {
            return;
        }

        grid[row][col] = '0';

        dfs(grid, row + 1, col);
        dfs(grid, row - 1, col);
        dfs(grid, row, col + 1);
        dfs(grid, row, col - 1);
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(m * n)
空间复杂度：O(m * n)
```

递归深度最坏可能达到 `m * n`。

# 十七、最短路径

## 1. 常见最短路径算法

| 算法 | 适用场景 |
|---|---|
| BFS | 无权图最短路径 |
| Dijkstra | 非负权图单源最短路径 |
| Bellman-Ford | 可处理负权边 |
| Floyd | 多源最短路径 |

---

## 2. Dijkstra 算法思想

Dijkstra 用于求：

```text
非负权图中，从起点到其他点的最短路径。
```

核心思想：

```text
1. dist[i] 表示起点到 i 的当前最短距离
2. 每次选择 dist 最小的未确定节点
3. 用该节点更新相邻节点距离
4. 重复直到所有节点处理完成
```

---

## 3. Java 代码：邻接表 + 优先队列

假设图用邻接表表示：

```text
graph[u] = [[v, weight], ...]
```

代码：

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.PriorityQueue;

public class Dijkstra {

    public int[] shortestPath(int n, int[][] edges, int start) {
        List<int[]>[] graph = new ArrayList[n];

        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }

        for (int[] edge : edges) {
            int from = edge[0];
            int to = edge[1];
            int weight = edge[2];

            graph[from].add(new int[]{to, weight});
        }

        int[] dist = new int[n];
        Arrays.fill(dist, Integer.MAX_VALUE);
        dist[start] = 0;

        PriorityQueue<int[]> heap = new PriorityQueue<>(
                (a, b) -> a[1] - b[1]
        );

        heap.offer(new int[]{start, 0});

        while (!heap.isEmpty()) {
            int[] curr = heap.poll();
            int node = curr[0];
            int distance = curr[1];

            if (distance > dist[node]) {
                continue;
            }

            for (int[] next : graph[node]) {
                int nextNode = next[0];
                int weight = next[1];

                if (dist[node] + weight < dist[nextNode]) {
                    dist[nextNode] = dist[node] + weight;
                    heap.offer(new int[]{nextNode, dist[nextNode]});
                }
            }
        }

        return dist;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O((V + E) log V)
空间复杂度：O(V + E)
```

---

## 5. 面试回答

如果是无权图最短路径，一般用 BFS。

如果是非负权图单源最短路径，一般用 Dijkstra。

如果存在负权边，可以用 Bellman-Ford。

如果要求任意两点之间的最短路径，可以用 Floyd。

# 十八、背包问题

## 1. 0/1 背包题目描述

有 `n` 个物品，每个物品只能选一次。

每个物品有：

```text
重量 weight[i]
价值 value[i]
```

背包容量为 `bagWeight`。

求背包能装下的最大价值。

---

## 2. 动态规划思路

定义：

```text
dp[j] 表示容量为 j 的背包能获得的最大价值。
```

状态转移：

```text
dp[j] = max(dp[j], dp[j - weight[i]] + value[i])
```

因为每个物品只能选一次，所以容量 `j` 要倒序遍历。

---

## 3. Java 代码

```java
public class Knapsack01 {

    public int maxValue(int[] weight, int[] value, int bagWeight) {
        int[] dp = new int[bagWeight + 1];

        for (int i = 0; i < weight.length; i++) {
            for (int j = bagWeight; j >= weight[i]; j--) {
                dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
            }
        }

        return dp[bagWeight];
    }
}
```

---

## 4. 为什么倒序遍历？

0/1 背包中，每个物品只能使用一次。

如果正序遍历，会导致同一个物品被重复使用。

所以必须倒序遍历容量。

---

## 5. 完全背包区别

完全背包中，每个物品可以使用无限次。

容量要正序遍历：

```java
for (int i = 0; i < weight.length; i++) {
    for (int j = weight[i]; j <= bagWeight; j++) {
        dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
    }
}
```

---

## 6. 复杂度分析

```text
时间复杂度：O(n * bagWeight)
空间复杂度：O(bagWeight)
```

# 十九、最长递增子序列

## 1. 题目描述

给定整数数组 `nums`，求最长严格递增子序列的长度。

示例：

```text
输入：[10,9,2,5,3,7,101,18]
输出：4
解释：[2,3,7,101]
```

---

## 2. 解法一：动态规划

定义：

```text
dp[i] 表示以 nums[i] 结尾的最长递增子序列长度。
```

状态转移：

```text
如果 nums[j] < nums[i]，
dp[i] = max(dp[i], dp[j] + 1)
```

---

## 3. Java 代码：动态规划

```java
import java.util.Arrays;

public class Solution {

    public int lengthOfLIS(int[] nums) {
        if (nums == null || nums.length == 0) {
            return 0;
        }

        int[] dp = new int[nums.length];
        Arrays.fill(dp, 1);

        int result = 1;

        for (int i = 1; i < nums.length; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }

            result = Math.max(result, dp[i]);
        }

        return result;
    }
}
```

---

## 4. 复杂度分析

```text
时间复杂度：O(n²)
空间复杂度：O(n)
```

---

## 5. 解法二：贪心 + 二分

维护一个数组 `tails`。

含义：

```text
tails[i] 表示长度为 i + 1 的递增子序列中，结尾元素的最小值。
```

遍历每个数字：

```text
如果它比所有 tails 都大，追加到后面；
否则用它替换第一个大于等于它的位置。
```

---

## 6. Java 代码：贪心 + 二分

```java
public class Solution {

    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;

        for (int num : nums) {
            int left = 0;
            int right = size;

            while (left < right) {
                int mid = left + (right - left) / 2;

                if (tails[mid] < num) {
                    left = mid + 1;
                } else {
                    right = mid;
                }
            }

            tails[left] = num;

            if (left == size) {
                size++;
            }
        }

        return size;
    }
}
```

---

## 7. 复杂度分析

```text
时间复杂度：O(n log n)
空间复杂度：O(n)
```
